نسخه ۳۶ — نمونه نمایشی تسهیلات مسکن

اجرا: start.bat یا سرو پوشه با python -m http.server 8000 و بازکردن http://localhost:8000
صفحه شروع: index.html

نقش‌ها: متقاضی، سرپرست اداری، بالاترین مقام اجرایی، مدیر سرمایه انسانی، کارشناس تحقیقات، کارشناس اداری.
گردش جدید: تأیید مقام اجرایی ← مدیر سرمایه انسانی (مبلغ مصوب و نظر کارگروه در صورت بررسی) ← بررسی و تحقیق (نتیجه و نظر) ← مدیر سرمایه انسانی (تأیید یا عدم تأیید همراه نظر) ← کارشناس اداری (وضعیت واریز، گزارش واریز و هماهنگی بانک) ← مدیر سرمایه انسانی (مشاهده گزارش).
ثبت مشاهده گزارش به معنای انجام واریز نیست؛ وضعیت واریز جداگانه در گزارش حفظ می‌شود.
سقف مبلغ درخواست و مبلغ مصوب: ۱۰٬۰۰۰٬۰۰۰٬۰۰۰ ریال (یک میلیارد تومان).
OTP نمایشی: 246810

اطلاعات محلی و نمایشی است؛ احراز هویت، کنترل دسترسی امن، ارسال پیامک واقعی و اتصال بانک وجود ندارد. برای داده حساس یا استفاده عملیاتی مناسب نیست.
برای ادامه پرونده‌های تأییدشده قبلی، وارد کارتابل مدیر سرمایه انسانی شوید.
